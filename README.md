# وزاريات الثالث متوسط – العراق

تطبيق Flutter عربي لطلبة الصف الثالث المتوسط في العراق، يضم أرشيف أوراق الامتحانات المصنفة ومساعداً تعليمياً يعمل عبر Cloudflare Worker وGemini.

## الموجود حالياً
- واجهة عربية من اليمين إلى اليسار.
- المواد الدراسية الثماني.
- أرشيف صور محلي داخل التطبيق، وليس عبر روابط صور خارجية.
- تصنيف الأوراق المتاحة حسب السنة والدور.
- بحث في الأرشيف حسب المادة والسنة والدور.
- حفظ أوراق الامتحان محلياً على الجهاز.
- مساعد تعليمي مع سياق للمحادثة وإعادة المحاولة ونسخ الإجابات.
- GitHub Actions لتحليل Flutter واختبار الواجهات وبناء APK وAAB.

## حالة المحتوى
الأوراق المصنفة المتوفرة حالياً في المستودع هي للعربية والكيمياء فقط. مجلدات بقية المواد مجهزة لاستقبال الصور، لكنها لا تحتوي بعد على أرشيف امتحانات. لا تُنشأ أسئلة أو سنوات أو أدوار افتراضية ولا تُنسب أوراق إلى الوزارة قبل التحقق من أصلها.

## التشغيل
```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## ملفات البناء
من تبويب Actions افتح آخر تشغيل ناجح ونزّل artifact باسم `third-intermediate-iraq-android-preview`. يحتوي APK للتثبيت وAAB للمعاينة التقنية. ملف AAB الحالي مخصص للمعاينة التقنية ويُبنى بتوقيع debug الافتراضي؛ لا ترفعه إلى Google Play كإصدار إنتاجي. توقيع الإصدار الحقيقي غير مفعّل بعد لأنه يتطلب keystore يملكه المطوّر، ثم إعداد Gradle وGitHub Secrets لاستخدامه.

## توقيع Google Play
أنشئ مفتاح رفع Android keystore واحتفظ بنسخة احتياطية آمنة. لا ترفع المفتاح أو كلمات المرور إلى Git. بعد توفير ملف المفتاح وكلمات المرور، يجب تفعيل إعداد التوقيع في Gradle وتهيئة GitHub Actions Secrets قبل إنشاء AAB إنتاجي موقع والتحقق منه في Play Console.

## المساعد الذكي
مفتاح Gemini يجب أن يبقى كـ Secret باسم `GEMINI_API_KEY` في Cloudflare Worker. لا تضعه في Flutter أو GitHub. بعد أي تعديل على `worker/src/index.js` يجب نشر Worker مجدداً حتى تصل التعديلات إلى المستخدمين.

## الخصوصية
راجع [سياسة الخصوصية](PRIVACY_POLICY.md). يجب نشرها على عنوان HTTPS عام وإدخال رابطها في Play Console قبل النشر.

## تنويه
التطبيق مشروع تعليمي مستقل وغير تابع لوزارة التربية العراقية. قد يخطئ المساعد الذكي؛ يجب مراجعة الحلول مع الكتاب المدرسي أو المدرس، ولا تُعد إجاباته حلولاً وزارية رسمية.
