# وزاريات الثالث متوسط – العراق

تطبيق Flutter عربي مستقل لطلبة الصف الثالث المتوسط في العراق.

## الموجود في النسخة التأسيسية
- واجهة عربية من اليمين إلى اليسار.
- الصفحة الرئيسية والمواد الدراسية الثماني.
- صفحة لكل مادة مع اختيار نوع الامتحان (وزاري/تمهيدي) والسنة.
- تبويبات الرئيسية والمواد والمحفوظات وحول التطبيق.
- GitHub Actions لتحليل المشروع واختباره وبناء APK.

## المواد
التربية الإسلامية، اللغة العربية، اللغة الإنكليزية، الرياضيات، الاجتماعيات، الأحياء، الكيمياء، الفيزياء.

## تشغيل محلي
```bash
flutter pub get
flutter run
```

## تنزيل APK
من تبويب Actions افتح أحدث تشغيل ناجح، ثم نزّل artifact باسم third-intermediate-iraq-release-apk.

## المحتوى والمصادر
الأرشيف الفعلي للأسئلة الأصلية والحلول المفصلة سيضاف تدريجياً بعد التحقق من السنة والمادة والدور والمصدر. لا تتضمن النسخة التأسيسية أسئلة تجريبية منسوبة إلى الوزارة. التطبيق مستقل وغير تابع لوزارة التربية العراقية.
