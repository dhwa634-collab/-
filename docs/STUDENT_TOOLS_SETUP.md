# إعداد ميزات دليلك للنجاح

## تواريخ الامتحانات
عدّل القيمتين في أعلى `lib/student_tools.dart` داخل `ExamDates` فقط:

```dart
static const DateTime? preparatory = DateTime(2027, 2, 1);
static const DateTime? ministerial = DateTime(2027, 6, 1);
```

هذه تواريخ توضيحية فقط وليست مواعيد رسمية. لا تضع أي تاريخ في التطبيق قبل التحقق من الجدول المعتمد. اترك القيمة `null` ليظهر «لم يُعلن».

## روابط الكتب
في القائمة `studyBooks` داخل الملف نفسه، أضف رابط PDF آمن يبدأ بـ HTTPS إلى الكتاب المقابل:

```dart
BookResource(
  'التربية الإسلامية',
  'كتاب التربية الإسلامية للثالث المتوسط',
  url: 'https://example.org/book.pdf',
),
```

استبدل الرابط بمصدر موثوق فعلي. عند عدم وجود رابط اتركه محذوفاً ليظهر الكتاب «قيد التجهيز». الروابط المتاحة تفتح في قارئ PDF خارجي على الجهاز وتتطلب الإنترنت.

## مؤقت الدراسة
من الشاشة يختار الطالب 25/5 أو 45/10 أو يحدد مدة بين 5 و120 دقيقة للدراسة وبين 1 و30 دقيقة للاستراحة. تحفظ حالة المؤقت وعدد جلسات اليوم محلياً باستخدام SharedPreferences.

## التحقق
- افتح الرئيسية ثم قسم الكتب PDF، وتأكد أن المواد الثماني تظهر وأن الكتب غير المرتبطة تظهر «قيد التجهيز».
- افتح عداد الامتحانات وتأكد أن كلا الموعدين يظهر «لم يُعلن» إلى حين إدخال التاريخ المعتمد.
- افتح المؤقت، جرّب بدء/إيقاف/إعادة ضبط وتغيير المدد، ثم أغلق الشاشة وافتحها للتحقق من حفظ الحالة.
- لا تتطلب هذه الميزات تعديلاً في Cloudflare Worker أو KV؛ مسارات المساعد والبلاغات بقيت كما هي.
